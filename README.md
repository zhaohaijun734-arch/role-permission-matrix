# role-permission-matrix

A complete "role -> permission point" authorization system for self-hosted
business apps (ERP / ticket / approval desks), including:

- frontend show/hide consistent with backend enforcement
- concurrent double-submit protection
- instant effect on role change
- account admin page
- forced password change on first login
- multi-person approval flows (who approves first, whose approval takes effect)

Ships as an agent SKILL.md: install by copying `SKILL.md` into your agent's
skills directory.
